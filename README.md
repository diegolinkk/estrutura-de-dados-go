# Estrutura de dados em Go
Recriação das estruturas de dados feitas na linguagem Go e usando o livro da Loiane como base de estudos.
# Pré requisitos
O único pré requisito é ter o [runtime do Go](https://go.dev/doc/install) instalado

# Executando o projeto
1. Entre na pasta data_structure
2. Execute `go run .`

# Executando exemplos
Eu posso importar os exemplos dos arrays para ver o seu funcionamento dentro da `main.go` ou posso importar diretamente as funções utilitárias:

```go
package main
import (
	"data_structures/arrays"
)

func main() {
	arrays.Exemplos_Arrays()
}
```
